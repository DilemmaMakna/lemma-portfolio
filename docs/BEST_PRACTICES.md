# Best Practices Checklist

Sources: only the SSG-for-content-sites, SEO/a11y deep-dive and layered-architecture points come from the GreatFrontEnd system design playbook (https://www.greatfrontend.com/front-end-system-design-playbook/framework). The rest is standard practice that is not verified against GreatFrontEnd, because their site has no reachable performance, SEO or project-structure guide.

Each item gives the practice, its status and where it lives in code. Status is one of `done`, `done in PR N.N` (the subtask in docs/TODO.md that finished it) or `todo` (with the planned subtask). Code locations were checked with grep and ls on branch feat/site-optimization.

Dependency decisions: `gsap`, `@gsap/react` and `lenis` stay. `lib/motion/gsap.ts` imports GSAP core and ScrollTrigger statically, and `components/providers/Providers.tsx` imports that module, so both load on every page. SplitText is imported only by `components/services/ServicesIntro.tsx`. Lenis loads with a dynamic import after mount in `components/layout/SmoothScroll.tsx`, and it is not loaded when reduced motion is set. The project has no framer-motion dependency or import. `sharp` is a devDependency used only by `scripts/optimize-work-photos.mjs`, so it does not ship to the browser.
