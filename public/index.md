## Working with Lemma

1. Conversation: describe the problem; the studio asks until the shape is clear.
2. Scope & proposal: scope, timeline, and price in one written document before work starts.
3. Build: structure first, visuals after, with visible progress at each stage.
4. Handover: everything is tested and documented so the client team can run it alone.
